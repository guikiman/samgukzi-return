# 저작권 근거 자료 (IP evidence)

특정 자산의 **출처가 확인되었다는 사실 자체가 아니라, 그 확인에 쓰인 원자료**를
보관한다. `assets/PROVENANCE.json` 의 항목이 "왜 이런 라이선스인가" 를 설명한다면,
여기는 "그 근거가 어디인가" 를 가리킨다.

> 이 디렉터리는 **배포 산출물이 아니다.** 게임 번들에도 서비스워커 캐시에도
> 들어가지 않는다. 근거 보관용이다.

### 왜 이게 필요한가

이 자산은 2026-09-30 에 처음 대장 등록을 시도했을 때 **근거 미확인**으로 걸렸다.
커밋 `73ff928` 이 "AI 원화"로 추가했지만, 생성 스크립트가 커밋에 없고 WebP 인코딩
시 메타데이터가 제거되어 **파일 내용만으로는 txt2img 인지 img2img 인지조차 알 수
없었다.** 이 상태에서 deny-list 게이트는 161커밋 전수 스캔을 통과시켜 버렸다.

txt2img 라면 입력 이미지가 없으므로 저작권된 원본에서 파생된 것이 아니고,
img2img 라면 Total War 파생 지도일 수 있었다 — 프로젝트가 실제로 겪은 사고 유형과
정확히 같은 결함이다. 그래서 확인이 필요했고, 확인의 근거가 이 캡처다.

### 검증 방법

캡처가 나중에 바뀌었는지 확인하려면 해시를 다시 계산하면 된다.

```bash
sha256sum docs/ip-evidence/map-china-ai-4096-provenance.png
```

값이 위 표와 다르면 근거 자료가 교체된 것이므로 `assets/PROVENANCE.json` 의
note 를 함께 고쳐야 한다.

### 한계 (이 기록이 주장하지 않는 것)

- 캡처는 **진술의 증거**이지 암호학적 출처 증명이 아니다. 이미지가 txt2img 로
  생성되었다는 사실을 기술적으로 증명할 수는 없다.
- `assets/PROVENANCE.json` 의 해당 항목 `source` 도 마찬가지로 **작성자 진술**을
  기록한 것이며, 게이트 스크립트가 독립 검증한 결과가 아니다.
- 생성 서비스(ChatGPT)의 결과물 이용 약관이 이 이미지에 적용된다.
