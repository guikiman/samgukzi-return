# 🎨 삼국지리턴 — 이미지 에셋 매니페스트 (인물 + 배경)

> 목적: 현재 구현된 시스템이 **실제로 참조/요구하는** 이미지 자산을 **사이즈별**로 전수 분류.
> 코드 근거와 기획서 체크리스트 번호를 함께 명시하여 아트 발주·아틀라스 설계의 단일 기준(SSoT)으로 사용한다.

## 1. 사이즈 티어 정의

| 티어 | 권장 해상도 | 종횡비 | 용도 | 렌더 경로 |
|---|---|---|---|---|
| **S** | 64×64 / 96×96 | 1:1 | 아이콘·썸네일·헥스 유닛 | 아틀라스(2048²) |
| **M** | 192×256 / 256×320 | 3:4 | 리스트 카드·이벤트 카드 | 아틀라스 |
| **L** | 512×640 / 768×768 | 4:5 | 무장 상세 흉상 | 스트리밍/아틀라스 |
| **XL** | 1024×1536 | 2:3 | 전신·컷인 일러스트 | 개별 텍스처 |
| **U-4K** | 2048×2731+ | 3:4 | Live2D 원본·풀스크린 컷인 | 개별 텍스처 |
| **BG** | 1920×1080 / 2560×1080 / 3840×2160 | 16:9·21:9 | 로비·이벤트·전투 배경 | 개별/압축 |

> WebGL 텍스처는 **2의 거듭제곱(POT)** 권장. 비-POT는 밉맵·압축 이슈 → 실제 발주는 최근접 POT로 스냅.
> S/M 티어는 **현재 `gpu_texture_atlas_packer` 기본값 2048×2048** 기준. 모바일은 `texture_streaming_manager`가 **512로 강제 다운스케일**.

## 6. 아틀라스 & 파일명 규칙 (코드 연계)

### 아틀라스 전략
- **S/M 티어** → `gpu_texture_atlas_packer`로 2048² 아틀라스에 패킹, `atlas_coord_dict`로 UV 조회
- **L/XL/U-4K** → `texture_streaming_manager` 개별 스트리밍(모바일 512 자동 다운스케일)
- **사용 안 하는 초상화** → `portrait_gc` LRU(최대 64)로 자동 해제
- **프리로드** → `event_preloader` / `lazy_load_manager`로 다음 턴 예상 이벤트·전투 에셋 선반입

### 권장 파일명 규칙
```
officer/{id}/{id}_{age}[_costume][_scar]_{tier}.webp
예) officer/guan_yu/guan_yu_aged_bust_l.webp
    officer/liu_bei/liu_bei_young_icon_s@2x.webp
bg/lobby/lobby_16x9.webp
bg/battle/terrain_forest_512.webp
ui/cursor/cursor_spring.svg
```

### 권장 포맷
| 용도 | 포맷 | 이유 |
|---|---|---|
| 알파 필요(복식/흉터/파츠) | **WebP(lossless)** | 알파 보존 + 용량 |
| 불투명 인물/배경 | **WebP(lossy q85)** 또는 AVIF | `[1091]` CDN·SW 캐싱 |
| 군기/커서 | **SVG** | `[1051]` 4K 무손실 |
| GPU 압축 텍스처 | **KTX2/Basis** | `compressed_texture_loader` |

## 7. 미구현 / 주의 사항
- 현재 리포지토리에는 **실제 이미지 파일이 존재하지 않음** (`src/data`는 `officers.json`만). 본 문서는 **발주/제작 기준 스펙**이다.
- `officers.json`의 무장 객체에는 아직 `portrait` 필드가 없음 → 초상화 매핑을 위해 `portrait_id` 필드 추가 필요.
- `OfficerBio.portrait?`(`officer_biography_store.ts`)가 유일한 초상화 참조 필드 → 에셋 경로 규칙과 연결 권장.
```
